# 프롤린 촉매 알돌 반응

> ketone + aldehyde --[L-proline(촉매), DMSO]--> enantioselective(거울상 선택적) β-hydroxy ketone. [enamine](../개념/엔아민.md)을 촉매 순환으로 만들어 쓰는 직접 비대칭 [aldol reaction](알돌%20반응.md)이다.

## 개요

[Stork enamine reaction](스토크%20엔아민%20반응.md)에서는 enamine을 화학양론적으로 만들어 썼다. 그렇다면 amine을 촉매로 돌려 쓸 수는 없을까? 2000년 List, Lerner, Barbas가 그 답을 보였다.[^1] amino acid L-proline이 enamine을 거쳐 직접 비대칭 aldol 반응을 촉매한 것이다. 이 업적은 2021년 노벨 화학상으로 이어졌다.[^2] (출처: L10 p.13)

## 메커니즘: 촉매 순환

proline은 어떻게 촉매로 돌아올까? 슬라이드의 촉매 순환을 한 바퀴 돌아 보자. (출처: L10 p.14)

1. **Enamine 형성.** 먼저 proline의 secondary amine이 ketone R¹–CO–CH₂R²를 공격해 carbinolamine **I**을 만든다. **I**에서 물이 빠지면 carboxylate와 짝을 이룬 iminium ion **II**가 되고, α-H를 잃으면 enamine **III**이 된다. 여기까지는 [enamine](../개념/엔아민.md) 형성과 같은 과정이다.
2. **C–C 결합 형성(핵심 단계).** enamine **III**에 RCHO가 다가오면 transition state **IV**에서 proline의 carboxylic acid H가 aldehyde 산소와 수소 결합을 한다. 그래서 aldehyde는 활성화되는 동시에 특정 방향으로 붙잡힌다. 이 상태에서 enamine의 α-탄소가 aldehyde carbonyl 탄소를 공격해 새 C–C 결합과 stereocenter가 생긴다. 즉 carboxylic acid는 electrophile을 활성화하면서 stereochemistry를 정하는 "손잡이" 역할을 한다.
3. **가수분해와 촉매 재생.** 공격 뒤에는 β-hydroxy iminium **V**가 생기고, 물이 더해져 carbinolamine **VI**이 된다. **VI**이 aldol 생성물 R–CH(OH)–CH(R²)–CO–R¹을 내놓으면 proline이 재생되어 다음 순환을 시작한다. 물은 I → II에서 빠졌다가 V → VI에서 다시 들어가므로 전체적으로는 소모되지 않는다.

슬라이드는 List 등이 처음 제안한 transition state **VII**도 함께 보여 준다.[^3] (출처: L10 p.14)

## 선택성

`acetone(20 vol%) + 4-nitrobenzaldehyde --[L-proline 30 mol%, DMSO]--> (R)-4-hydroxy-4-(4-nitrophenyl)butan-2-one`, 68 % 수율, 76 % ee (출처: L10 p.13)

acetone이 enamine(nucleophile)이 되고, aldehyde가 electrophile이다. 생성물은 CH₃CO–CH₂–CH(OH)–Ar이다. 다른 aldehyde로 넓혀 본 결과는 아래와 같다. (출처: L10 p.13)

| 생성물 | aldehyde의 R | 수율 | ee |
|---|---|---|---|
| 34a | 4-NO₂C₆H₄ | 68 % | 76 % |
| 34b | Ph | 62 % | 72 % |
| 34c | 4-BrC₆H₄ | 74 % | 65 % |
| 34d | 2-ClC₆H₄ | 94 % | 69 % |
| 34e | 2-naphthyl | 54 % | 77 % |
| 34f | i-Pr | 97 % | 96 % |
| 34g | cyclohexyl | 63 % | 84 % |
| 34h | tert-butyl | 81 % | >99 % |
| 34i | C(CH₃)₂CH₂CH=CH₂ | 85 % | >99 % |

aromatic aldehyde는 ee가 중간 정도(65–77 %)인 반면, α-branched aliphatic aldehyde, 특히 α-탄소가 quaternary(4차)인 34h와 34i는 ee가 >99 %에 이른다. 모든 생성물의 OH가 같은 방향 쐐기로 그려져 있다는 점에서, 같은 면 facial selectivity이 일관되게 나타남을 알 수 있다(→ [stereoselectivity](../개념/입체특이성과%20입체선택성.md)). (출처: L10 p.13)

## 예

- acetone + 4-nitrobenzaldehyde --[L-proline 30 mol%, DMSO]--> (R)-aldol (68%, 76% ee) (출처: L10 p.13)
- acetone + isobutyraldehyde((CH₃)₂CHCHO) --[L-proline 30 mol%, DMSO]--> 34f CH₃COCH₂CH(OH)CH(CH₃)₂ (97%, 96% ee) ([L10 연습 문제](../../practice/L10_Exercises.md) 8번) (출처: L10 p.13)

## 흔한 오해

- **"proline의 역할은 amine뿐이다"**: carboxylic acid도 aldehyde와 수소 결합해 활성화와 stereocontrol(입체 제어)을 맡는다. (출처: L10 p.14)
- **"비대칭 유도에는 [chiral auxiliary](../개념/키랄%20보조기.md)를 붙였다 떼야 한다"**: 여기서는 chiral catalyst가 순환하므로 auxiliary를 붙이고 떼는 단계가 없다. 보충: Evans auxiliary는 화학양론적으로 붙였다 떼는 방식이다(→ [Evans oxazolidinone](../시약/에반스%20옥사졸리디논.md)). (보충 근거: Clayden p.1109)
