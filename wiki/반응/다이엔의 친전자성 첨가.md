# 다이엔의 친전자성 첨가

> conjugated diene에 HBr이나 Br₂를 더하면 [allyl cation](../개념/알릴%20양이온.md)(또는 그에 준하는 intermediate)을 거쳐 **1,2-adduct와 1,4-adduct**가 생긴다. 낮은 온도에서는 1,2-adduct(kinetic), 가열하면 1,4-adduct(thermodynamic)가 우세하다.

## 개요

diene에서는 regioselectivity 문제가 **두 번** 나온다. 첫째, electrophile이 **어느 이중결합의 어느 끝**에 붙는가. 둘째, 생긴 allyl cation의 **어느 끝**을 nucleophile이 공격하는가. 두 번째 선택은 슬라이드에서 **allyl cation과 bromide 사이의 regioselectivity**라고 따로 구분해 둔다. 그리고 두 생성물이 서로 바뀔 수 있으면 온도가 생성물을 고른다([kinetic vs thermodynamic control](../개념/속도론적%20지배와%20열역학적%20지배.md)). (출처: L2 p.5–6)

## 메커니즘

### isoprene + HBr

isoprene(2-methyl-1,3-butadiene)에 H⁺가 붙는 경우를 보자. (출처: L1 p.19)
- **methyl이 붙은 쪽 이중결합**의 말단에 H⁺가 붙으면 **allylic cation**이 생긴다. 양전하가 resonance로 퍼지며, 그중 한 공명 구조에서는 양전하가 methyl이 붙은 3차 탄소에 놓여 추가로 안정화된다.
- **다른 쪽 이중결합**에 H⁺가 붙어도 allylic cation이 생기지만, 양전하가 methyl이 붙은 탄소까지 퍼지지 않는다. 그래서 methyl의 안정화 효과를 받지 못한다.

따라서 앞의 경로가 선택된다. 이렇게 생긴 allyl cation을 Br⁻가 공격하는데, 공격은 **덜 붐비는 말단**에서 일어난다. 생성물은 **prenyl bromide**이다. 결과적으로 H와 Br이 **diene 계의 양 끝(1,4 위치)**에 붙는다. (출처: L1 p.19, L2 p.5)

### 1,3-butadiene + Br₂ (1 당량)

슬라이드 L1 p.20은 빈칸으로 남겨져 있고, 답은 L2 p.6에 나온다. [bromonium ion](../개념/브로모늄%20이온.md)이 생긴 뒤 Br⁻가 가까운 탄소(고리 탄소)를 바로 공격하면 1,2-생성물이 된다. 반면 이웃한 이중결합을 통해 고리가 열리면서 먼 끝(4번 탄소)이 공격받으면 1,4-생성물이 된다. 슬라이드에서 두 반응은 가역 화살표(⇌)로 그려져 있다. 그래서 충분한 에너지를 주면 더 안정한 생성물로 모이고, 결국 diene 계의 **양 끝에 Br 두 개**가 붙는다. (출처: L1 p.20, L2 p.6)

## 선택성

| 조건 | 주생성물 | 구분 |
|---|---|---|
| 0 °C | 3,4-dibromo-1-butene (1,2-첨가) | kinetic product |
| 가열 | (*E*)-1,4-dibromo-2-butene (1,4-첨가) | thermodynamic product |

(출처: L2 p.6)

온도를 높이면 더 안정한 1,4-생성물, 즉 이치환 내부 alkene 쪽으로 쏠린다.[^1] (출처: L1 p.20, L2 p.6)

## 예

- `isoprene --[HBr]--> prenyl bromide` (1,4-첨가) (L1, 출처: L1 p.19)
- `1,3-butadiene --[Br₂, 0 °C]--> 3,4-dibromo-1-butene` / `--[Br₂, 가열]--> (E)-1,4-dibromo-2-butene` (L1–L2, 출처: L2 p.6)

## 흔한 오해

- "diene에도 electrophile이 한 이중결합에만 붙고 끝난다": resonance로 퍼진 양전하 때문에 먼 끝(4번 탄소)에도 nucleophile이 붙는다. (출처: L1 p.19–20)
- "1,2-adduct가 더 안정해서 먼저 생긴다": 먼저(빨리) 생기는 것과 더 안정한 것은 다르다. 1,2-adduct는 빨리 생기고, 1,4-adduct가 더 안정하다. (출처: L2 p.6)
- "nucleophile은 양전하가 더 안정한 쪽 끝을 공격한다": isoprene + HBr에서 Br⁻는 덜 붐비는 말단을 공격한다. cation의 생성 위치(1단계)와 nucleophile의 공격 위치(2단계)는 따로 따져야 한다(→ [allyl cation](../개념/알릴%20양이온.md)). (출처: L1 p.19, L2 p.5)
- 이름이 같은 "1,2-/1,4-첨가"가 L11의 enone 첨가에도 나오지만, 그쪽은 nucleophile이 붙는 반응이다(→ [1,2-addition vs 1,4-addition](../개념/1,2-첨가와%201,4-첨가.md)).
