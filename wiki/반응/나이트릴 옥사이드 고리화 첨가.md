# 나이트릴 옥사이드 고리화 첨가

> 니트릴 옥사이드(R–C≡N⁺–O⁻) + 알켄 → isoxazoline, + 알카인 → isoxazole. 알켄의 Z/E 정보가 고리의 cis/trans를 거쳐 알돌의 syn/anti로 이어진다.

## 개요

니트릴 옥사이드는 삼중결합형 [[1,3-쌍극자]]라, 고리화 첨가 뒤 고리 안에 C=N 이중결합이 하나 남는다. 그 자체보다 **다른 것으로 바뀌는 능력**이 쓸모 있다. N–O 결합을 끊어 1,3-아미노알코올이나 β-하이드록시 케톤([[알돌 반응|알돌]] 생성물)을 얻는다. (출처: L15 p.14, p.20)

## 니트릴 옥사이드 만들기

불안정해서 반응계 안에서 만든다.[^1] MeCHO --[1. H2N–OH; 2. Cl2; 3. NEt3]--> Me–C≡N⁺–O⁻ (출처: L15 p.17)

1. 알데하이드 + 하이드록실아민 → 옥심 MeCH=N–OH
2. OH 산소 전자쌍의 도움으로 C=N 탄소가 Cl–Cl을 공격(Cl⁻ 이탈) → Me–CH(Cl)–N=O⁺H
3. C–H 양성자가 빠져 하이드록시모일 클로라이드 MeC(Cl)=N–OH
4. NEt3가 O–H를 떼어 MeC(Cl)=N–O⁻
5. 산소 음이온 전자가 N 쪽으로 밀려 들어가며 Cl⁻ 이탈 → Me–C≡N⁺–O⁻

## 선택성

- **입체특이성:** 협동적 초면-초면 [3+2]라 알켄 기하가 보존된다. (Z)-알켄 → 4,5-*cis*, (E)-알켄 → 4,5-*trans* isoxazoline (→ [[입체특이성과 입체선택성]]). (출처: L15 p.19)
- **위치선택성(말단 알카인):** 치환된 탄소가 O와 결합해 R이 C5(O 옆)에 오는 3,5-이치환 isoxazole이 생긴다. 고리에 이중결합이 두 개가 되어 방향족이다. (출처: L15 p.19)

## 예

- R'–C≡N⁺–O⁻ + (Z)-RCH=CHR → 3-R'-4,5-*cis*-다이R-isoxazoline (출처: L15 p.19)
- R'–C≡N⁺–O⁻ + HC≡C–R → 3-R'-5-R-isoxazole (출처: L15 p.19)
- isoxazoline --[LiAlH4]--> 1,3-아미노알코올 R–CH(NH2)–CH2–CH(OH)–R (C=N 환원 + N–O 절단) (출처: L15 p.20)
- isoxazoline --[H2/Ni, H2O]--> β-하이드록시 이민 → 가수분해 → β-하이드록시 케톤(알돌 생성물). ***cis*-isoxazoline은 syn-알돌, *trans*는 anti-알돌**을 준다. (출처: L15 p.20)

## 흔한 오해

- "isoxazole, isoxazoline, isoxazolidine은 같다": 각각 방향족(니트릴 옥사이드 + 알카인), 이중결합 하나(니트릴 옥사이드 + 알켄), 완전 포화([[나이트론 고리화 첨가|니트론]] + 알켄)다. (출처: L15 p.15–19)
- "isoxazoline을 환원하면 항상 아미노알코올": [[LiAlH4]]는 아미노알코올을, H2/Ni + H2O는 질소가 가수분해로 빠진 β-하이드록시 케톤을 준다. (출처: L15 p.20)
