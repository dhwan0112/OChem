# 탄소 양이온

> 탄소가 결합 셋만 갖고 양전하를 띤 **reactive intermediate**다. alkyl기·resonance가 많이 안정화할수록 잘 생기며, 이 하나의 원리로 Markovnikov's rule, Friedel–Crafts rearrangement, E1 dehydration, Boc deprotection이 모두 설명된다.

## 개요

carbocation은 빈 p orbital을 가진 강한 electrophile이라서, 아무리 약한 nucleophile(물, benzene 고리)과도 반응한다. 반응이 carbocation을 거칠 때는 **어느 cation이 더 안정한가**가 regioselectivity를 정하고, 더 안정한 cation으로 바뀔 수 있으면 [rearrangement](탄소%20양이온%20자리옮김.md)가 일어난다. (출처: L3 p.15–16)

## 안정성

- **alkyl 치환**: CH₃⁺ < CH₃CH₂⁺ < (CH₃)₂CH⁺ < (CH₃)₃C⁺. 1차 cation은 용액에서 사실상 존재하지 못한다. (출처: L3 p.16–17)
- **resonance**: benzylic cation(Ph 옆)과 [allyl cation](알릴%20양이온.md)은 양전하가 resonance로 퍼져 안정하다. (출처: L1 p.17, p.19)

보충: alkyl기가 cation을 안정화하는 것은 이웃 C–H/C–C σ 결합이 빈 p orbital에 전자를 나눠 주는 hyperconjugation(초공액) 때문이라고 표준 교재(Clayden 등)는 설명한다. (보충 근거: Clayden p.335)

## 강의별로 보면

| 강의 | 반응 | carbocation의 역할 |
|---|---|---|
| L1 | [HBr 첨가](../반응/할로젠화수소%20첨가.md) | H⁺가 붙어 더 안정한(3차, benzylic) cation이 생기고 Br⁻가 잡는다 → [Markovnikov's rule](마르코프니코프%20규칙.md) (출처: L1 p.16–18) |
| L2 | [acid-catalyzed hydration](../반응/산%20촉매%20수화.md), TFA 첨가 | 3차 cation을 만들 수 있을 때만 hydration이 잘 된다. 평형이며 역반응은 E1 dehydration (출처: L2 p.19–20) |
| L3 | [Friedel–Crafts alkylation](../반응/프리델-크래프츠%20알킬화.md) | AlCl₃가 R–Cl에서 R⁺를 만들어 benzene이 공격. 1차는 rearrangement (출처: L3 p.15–17) |
| L3–L4 | [electrophilic aromatic substitution](../반응/친전자성%20방향족%20치환.md) | cyclohexadienyl cation([arenium ion](아레늄%20이온.md)). toluene의 o/p 배향은 3차 cation 공명 구조 때문 (출처: L3 p.11, L4 p.8–9) |
| L8, L10 | 산 촉매 aldol condensation의 dehydration | 3차 OH가 protonation → H₂O 이탈 → 3차 cation → α-H 이탈(E1) (출처: L8 p.13, L10 p.3) |
| L12 | [Boc protecting group](../시약/Boc%20보호기.md) 제거 | 산에서 3차 *t*-butyl cation이 떨어지는 SN1형 이탈 (출처: L12 p.10) |

![isobutene에 HBr이 첨가되어 3차 carbocation을 거치는 메커니즘](../../figures/L01/hbr_markovnikov.svg)

*그림: H는 CH₂ 쪽에 붙고 양전하는 methyl 두 개가 안정화하는 3차 탄소에 남는다. 이어서 Br⁻가 그 cation을 잡는다.*

## 흔한 오해

- "Br₂ 첨가도 carbocation을 거친다": Br₂ 첨가는 [bromonium ion](브로모늄%20이온.md)을 거친다. carbocation이었다면 양쪽 면 공격으로 syn/anti가 섞였겠지만, cyclohexene은 *trans*-dibromide 하나만 준다. (출처: L2 p.10)
- "acylation도 cation이니 rearrangement가 일어난다": [acylium ion](아실륨%20이온.md)은 산소의 비공유 전자쌍이 양전하를 나눠 가져 충분히 안정하므로 rearrangement가 일어나지 않는다. (출처: L3 p.18, p.21)
- "산성 dehydration은 E1cB다": 염기성 aldol dehydration은 [E1cB elimination](E1cB%20제거.md)이지만, 산성 dehydration은 슬라이드 표기대로 carbocation을 거치는 E1이다. (출처: L8 p.13)
