# 탄소 양이온

> 탄소가 결합 셋만 갖고 양전하를 띤 **반응성 중간체**다. 알킬기·공명이 많이 안정화할수록 잘 생기며, 이 하나의 원리로 마르코프니코프 규칙, 프리델-크래프츠 자리옮김, E1 탈수, Boc 탈보호가 모두 설명된다.

## 개요

탄소 양이온은 빈 p 궤도함수를 가진 강한 친전자체라서, 아무리 약한 친핵체(물, 벤젠 고리)와도 반응한다. 반응이 탄소 양이온을 거칠 때는 **어느 양이온이 더 안정한가**가 위치선택성을 정하고, 더 안정한 양이온으로 바뀔 수 있으면 [[탄소 양이온 자리옮김|자리를 옮긴다]]. (출처: L3 p.15–16)

## 안정성

- **알킬 치환**: CH₃⁺ < CH₃CH₂⁺ < (CH₃)₂CH⁺ < (CH₃)₃C⁺. 1차 양이온은 용액에서 사실상 존재하지 못한다. (출처: L3 p.16–17)
- **공명**: 벤질 양이온(Ph 옆)과 [[알릴 양이온]]은 양전하가 공명으로 퍼져 안정하다. (출처: L1 p.17, p.19)

보충: 알킬기가 양이온을 안정화하는 것은 이웃 C–H/C–C σ 결합이 빈 p 궤도함수에 전자를 나눠 주는 초공액(hyperconjugation) 때문이라고 표준 교재(Clayden 등)는 설명한다.

## 강의별로 보면

| 강의 | 반응 | 탄소 양이온의 역할 |
|---|---|---|
| L1 | [[할로젠화수소 첨가|HBr 첨가]] | H⁺가 붙어 더 안정한(3차, 벤질) 양이온이 생기고 Br⁻가 잡는다 → [[마르코프니코프 규칙]] (출처: L1 p.16–18) |
| L2 | [[산 촉매 수화]], TFA 첨가 | 3차 양이온을 만들 수 있을 때만 수화가 잘 된다. 평형이며 역반응은 E1 탈수 (출처: L2 p.19–20) |
| L3 | [[프리델-크래프츠 알킬화]] | AlCl₃가 R–Cl에서 R⁺를 만들어 벤젠이 공격. 1차는 자리옮김 (출처: L3 p.15–17) |
| L3–L4 | [[친전자성 방향족 치환]] | 사이클로헥사다이엔일 양이온([[아레늄 이온]]). 톨루엔의 o/p 배향은 3차 양이온 공명 구조 때문 (출처: L3 p.11, L4 p.8–9) |
| L8, L10 | 산 촉매 알돌 축합의 탈수 | 3차 OH가 양성자화 → H₂O 이탈 → 3차 양이온 → α-H 이탈(E1) (출처: L8 p.13, L10 p.3) |
| L12 | [[Boc 보호기]] 제거 | 산에서 3차 *t*-뷰틸 양이온이 떨어지는 SN1형 이탈 (출처: L12 p.10) |

![아이소뷰텐에 HBr이 첨가되어 3차 탄소 양이온을 거치는 메커니즘](../../figures/L01/hbr_markovnikov.svg)

*그림: H는 CH₂ 쪽에 붙고 양전하는 메틸 두 개가 안정화하는 3차 탄소에 남는다. 이어서 Br⁻가 그 양이온을 잡는다.*

## 흔한 오해

- "Br₂ 첨가도 탄소 양이온을 거친다": Br₂ 첨가는 [[브로모늄 이온]]을 거친다. 탄소 양이온이었다면 양쪽 면 공격으로 syn/anti가 섞였겠지만, 사이클로헥센은 *trans*-다이브로마이드 하나만 준다. (출처: L2 p.10)
- "아실화도 양이온이니 자리를 옮긴다": [[아실륨 이온]]은 산소의 비공유 전자쌍이 양전하를 나눠 가져 충분히 안정하므로 자리를 옮기지 않는다. (출처: L3 p.18, p.21)
- "산성 탈수는 E1cB다": 염기성 알돌 탈수는 [[E1cB 제거]]지만, 산성 탈수는 슬라이드 표기대로 탄소 양이온을 거치는 E1이다. (출처: L8 p.13)
