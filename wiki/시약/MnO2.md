# MnO2

> manganese dioxide. 매우 순한 산화제라 **allyl·benzyl alcohol만** 골라 aldehyde나 ketone으로 바꾼다. 일반 alcohol은 그대로 남는다.

## 개요

MnO₂는 너무 순해서 아무 alcohol이나 산화하지 못한다. 그런데 이 "편식"이 오히려 장점이다. 한 분자에 OH가 여러 개 있을 때 C=C나 aromatic ring 옆의 OH만 골라 산화할 수 있기 때문이다. 슬라이드는 이 시약을 "Mn–O" 산화제로 부른다. (출처: L6c p.10)

## 무엇을 하나

| 기질 | 생성물 | 비고 |
|---|---|---|
| allyl 1차 alcohol | α,β-불포화 aldehyde | C=C 유지 |
| allyl 2차 alcohol | enone | |
| benzyl alcohol | 방향족 aldehyde·ketone | |
| 일반(비allyl) alcohol | 반응 없음 | |

(출처: L6c p.10, p.17)

## 예

- retinol(vitamin A, polyene allyl 1차 alcohol) --[MnO₂]--> retinal(>95%)
- steroid형 diol: C=C 옆 allyl 2차 OH만 산화되어 enone이 되고, allyl이 아닌 2차 OH는 그대로 남는다.
- geraniol도 allyl 1차 alcohol이라 MnO₂로 geranial을 만들 수 있다.

(출처: L6c p.10)

## 이웃 시약과 비교

- **[DMP](DMP.md)·[Swern](../반응/스원%20산화.md)·[TPAP](TPAP.md)·[TEMPO](TEMPO.md):** 1차·2차 alcohol을 가리지 않고 산화한다. allyl OH만 골라야 한다면 MnO₂다. (출처: L6c p.17)
- **[SeO2](SeO2.md):** 이름이 비슷한 "allyl 산화"지만 SeO₂는 산소가 없는 allyl **C–H**(methyl)를 CHO로 바꾼다. MnO₂는 이미 있는 allyl **OH**를 산화한다. (출처: L6c p.10, p.18)

## 흔한 오해

- "MnO₂는 환원제": 원본 슬라이드 p.10에 "very mild reducing reagent"라고 잘못 적혀 있었고, 수정본은 "oxidizing reagent"로 고쳤다. 매우 순한 **산화제**다. (출처: L6c p.10)
- "순하니까 모든 alcohol을 천천히 산화한다": allyl·benzyl alcohol만 산화한다.
