# MnO2

> 이산화망간. 매우 순한 산화제라 **알릴·벤질 알코올만** 골라 알데하이드나 케톤으로 바꾼다. 일반 알코올은 그대로 남는다.

## 개요

MnO₂는 너무 순해서 아무 알코올이나 산화하지 못한다. 그런데 이 "편식"이 오히려 장점이다. 한 분자에 OH가 여러 개 있을 때 C=C나 방향족 고리 옆의 OH만 골라 산화할 수 있기 때문이다. 슬라이드는 이 시약을 "Mn–O" 산화제로 부른다. (출처: L6c p.10)

## 무엇을 하나

| 기질 | 생성물 | 비고 |
|---|---|---|
| 알릴 1차 알코올 | α,β-불포화 알데하이드 | C=C 유지 |
| 알릴 2차 알코올 | 엔온 | |
| 벤질 알코올 | 방향족 알데하이드·케톤 | |
| 일반(비알릴) 알코올 | 반응 없음 | |

(출처: L6c p.10, p.17)

## 예

- 레티놀(비타민 A, 폴리엔 알릴 1차 알코올) --[MnO₂]--> 레티날(>95%)
- 스테로이드형 다이올: C=C 옆 알릴 2차 OH만 산화되어 엔온이 되고, 알릴이 아닌 2차 OH는 그대로 남는다.
- 제라니올도 알릴 1차 알코올이라 MnO₂로 제라니알을 만들 수 있다.

(출처: L6c p.10)

## 이웃 시약과 비교

- **[[DMP]]·[[스원 산화|Swern]]·[[TPAP]]·[[TEMPO]]:** 1차·2차 알코올을 가리지 않고 산화한다. 알릴 OH만 골라야 한다면 MnO₂다. (출처: L6c p.17)
- **[[SeO2]]:** 이름이 비슷한 "알릴 산화"지만 SeO₂는 산소가 없는 알릴 **C–H**(메틸)를 CHO로 바꾼다. MnO₂는 이미 있는 알릴 **OH**를 산화한다. (출처: L6c p.10, p.18)

## 흔한 오해

- "MnO₂는 환원제": 원본 슬라이드 p.10에 "very mild reducing reagent"라고 잘못 적혀 있었고, 수정본은 "oxidizing reagent"로 고쳤다. 매우 순한 **산화제**다. (출처: L6c p.10)
- "순하니까 모든 알코올을 천천히 산화한다": 알릴·벤질 알코올만 산화한다.
