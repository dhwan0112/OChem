# 반응 메커니즘 그림 그리기 지침

이 저장소의 모든 메커니즘 그림이 따르는 규칙이다. 학습자와 피드백을 주고받으며 정한 내용이므로 새 그림을 그릴 때 반드시 지킨다.

## 1. 도구와 작업 흐름

1. 그림 하나는 `figures/L##/<이름>.json` 스펙 하나로 정의한다(형식은 `tools/chemfig.py` 맨 위 설명 참고).
2. `RESHIKI=<reshiki 실행 파일> python3 tools/chemfig.py figures/L##/<이름>.json`으로 SVG를 만든다.
3. **반드시 렌더링 결과를 눈으로 확인한다.** 라이트와 다크 두 모드 모두, 2배에서 4배로 확대해서 본다. 겹치는 부분은 확대 크롭으로 다시 확인한다.
4. 노트에는 `![설명](../figures/L##/<이름>.svg)`로 넣고, 그 아래 줄에 `그림: …` 형식(기울임 `*…*`으로 감싸지 않음. GitHub에서 인라인 LaTeX가 렌더되도록)으로 색과 화살표의 의미를 설명한다.

ReShiki는 굽은 화살표를 네이티브로 지원한다. 전자쌍 화살표(`curved`)와 전자 하나 화살표(`fishhook`)가 있고, 화살표를 원자, 결합, 비공유 전자쌍에 부착할 수 있다. CLI의 compose 스키마에는 직선 화살표만 있지만, `chemfig.py`가 .rsk(JSON) 문서에 굽은 화살표를 직접 써 넣어서 해결한다.

## 2. 구조 표기

- **수소는 명시한다.** C=C, C–H, O–H 등 메커니즘에 관여하는 탄소의 수소는 모두 그린다. 골격식(skeletal)에서 수소를 생략하지 않는다.
- 결합 길이 1(=42 SVG 단위)을 기준으로 좌표를 잡고 sp² 120°, sp³ 109.5°(2D에서는 120°) 배치를 지킨다.
- 전하는 원자 라벨에 표시한다(Br⁺, Br⁻ 등).
- 입체화학은 쐐기(`wedge`)와 점선 쐐기(`hash`)로 나타낸다.

## 3. 색 규칙 (라이트/다크 자동 전환)

| 이름 | 의미 | 라이트 | 다크 |
|---|---|---|---|
| ink | 기본 선과 글자 | #1b1b1f | #e6e6ea |
| nu | 친핵체 쪽 (전자를 주는 결합/원자, HOMO) | 파랑 #1d4ed8 | #8ab4ff |
| el | 친전자체 쪽 (전자를 받는 결합/원자, LUMO) | 빨강 #b91c1c | #ff8a8a |
| arrow | 굽은 화살표 (전자 이동) | 주황 #c2410c | #ff9f5a |
| good | 생성되는 결합, 강조 | 초록 | |
| muted | 설명 문구, 이름 | 회색 | |

- 학습자는 주로 **다크 모드**로 본다. SVG는 `prefers-color-scheme`으로 색이 바뀐다.
- SVG에는 모드에 맞춘 둥근 배경 카드(라이트 #ffffff, 다크 #1e1e1e, 옵시디언 기본 배경색)를 `chemfig.py`가 자동으로 넣는다. 옵시디언 테마와 운영체제 설정이 엇갈려도 선과 글자가 배경에 묻히지 않게 하기 위해서다.

## 4. 굽은 화살표 배치 규칙

- **화살표 머리가 비공유 전자쌍, 결합선, 원자 라벨과 겹치면 안 된다.** 겹치면 다음 순서로 고친다.
  1. 화살표가 닿는 방향(`dir`)을 빈 공간 쪽으로 돌린다. 기본값은 곡선이 다가오는 방향이다.
  2. `gap`을 늘려 머리를 대상 앞에서 멈추게 한다. 라벨 없는 탄소는 5–7, 라벨 있는 원자는 3 정도로 잡는다.
  3. 그래도 겹치면 원자 배치를 바꾼다. 예: 에틸렌을 눕히고 Br₂를 위에서 접근시킨다.
- **같은 영역에서 나가는 화살표와 들어오는 화살표는 반대 방향으로 휘게** 하여 괄호 `( )`처럼 대칭으로 보이게 한다. 예: π→Br 화살표는 왼쪽으로, Br 전자쌍→C 화살표는 오른쪽으로 휜다.
- 비공유 전자쌍에서 출발하는 화살표는 그 전자쌍(`{"lp": [원자, 각도]}`)에서 시작한다. 화살표가 들어오는 자리에는 전자쌍을 두지 않는다.
- 전자쌍은 메커니즘에 쓰이는 것만 그린다. 다 그리면 복잡해진다(슬라이드 관례와 같다).
- 결합에서 출발하는 화살표는 결합 중점(`{"bond": [a, b]}`)에서 시작한다. 원자 순서는 도구가 자동으로 맞춘다.
- 공명 구조 사이에는 공명 화살표 `[x1, y1, x2, y2, "resonance"]`를 쓴다. 평형은 `"equilibrium"`이다.
- 비공유 전자쌍에서 같은 원자가 포함된 결합으로 가는 화살표(예: N의 전자쌍이 C–N 결합으로 가서 C=N을 만드는 경우)는 ReShiki가 부착을 거부한다. 이때는 끝점을 결합 근처의 `pt`로 둔다.
- 짧은 결합(예: Br–Br) 위의 화살표가 너무 작으면 결합을 길게 그린다.
- 화살표 곡선은 C–H 결합 사이의 빈 공간을 지나가게 한다.

## 5. 그림 안의 글자

- 캡션과 라벨은 **영어와 기호로만** 쓴다(예: `backside attack (SN2)`, `π (HOMO)`). ReShiki의 기본 글꼴(DejaVu Sans)에는 한글이 없어서 글자 폭이 잘못 계산되고 글자가 겹친다. 한국어 설명은 노트의 그림 설명문에 쓴다.
- 캡션은 원자 라벨(10pt)보다 작게 쓴다. 기본 8pt, δ+ 같은 기호는 7pt이며, `[텍스트, x, y, 색, 크기]`로 지정한다.
- 아래 첨자 표기(S_N2 등)는 그대로 쓰면 밑줄이 보이므로 `SN2`처럼 쓴다.

## 6. 내용 규칙

- 그림은 슬라이드의 메커니즘과 같아야 한다. 스펙의 `title`에 근거 슬라이드(`L# p.N`, PDF 페이지)를 적는다.
- 슬라이드에 없는 해석을 그림에 넣을 때는 노트 본문에서 "보충:"으로 밝힌다.
- 한 그림에는 한 단계(또는 짧은 두 단계)만 담는다. 단계가 많으면 그림을 나눈다.

## 7. ReShiki로 못 그리는 것: 로브, 3D 구조, 에너지 도표

기존 ReShiki 그림의 실측 규격(화면 표시 기준, SVG 단위 × 0.62 = px):

| 항목 | 값 |
|---|---|
| 결합 길이 | 42 단위 = 약 26 px |
| 결합선 굵기 | 1.75 단위 = 약 1.1 px (채운 다각형) |
| 글꼴 | DejaVu Sans, 보통체 |
| 원자 라벨 | 29.2 단위(10 pt) = 약 18 px, 기본 ink. 원소 색이 아니라 **역할 색**(nu 파랑, el 빨강, good 초록)만 쓴다 |
| 캡션 | 23.3 단위(8 pt) = 약 14.5 px, muted; 작은 기호 20.4 단위(7 pt) = 약 12.7 px |
| 전하 | 원자 라벨 오른쪽 위 작은 글씨(Br⁺) |
| 굽은 화살표 | arrow 색, 채운 머리 |
| 배경 | 둥근 카드(rx 14 단위 = 약 8.7 px), 라이트 #ffffff / 다크 #1e1e1e, 여백 약 11.7 단위 = 7 px, 테두리·축·제목 없음 |
| 다크 모드 | SVG 안의 `prefers-color-scheme` CSS로 자동 전환 |

- **p 오비탈 로브**는 `chemfig.py`의 `shapes`(`lobe`, `line`)로 ReShiki 그림 위에 같은 좌표계로 그린다. 채운 로브가 + 위상, 빈 로브가 − 위상이다(nu 색, 선 굵기는 결합과 같다).
- **3D 구조/TS와 에너지 도표**는 `tools/visual_boost.py`가 `tools/mplfig.py`(위 규격의 `PX` 표, CSS 변수 색, 같은 카드)와 `tools/mol3dfig.py`로 만든다. 3D 그림은 공-막대가 아니라 chemfig와 같은 선 그림이다: C는 꼭짓점, 다른 원자는 18 px 라벨(배경색 바탕으로 결합을 끊음), 앞쪽 결합은 ink, 뒤쪽 결합은 muted, 형성/절단 결합은 good 점선. 3D 투영은 결합이 짧아 보이므로 34 px/Å로 그린다.
- 3D 좌표는 `figures/xyz/`에 둔다. GFN2-xTB로 최적화했고, TS는 형성·절단 결합 길이를 고정한 근사 구조다. 그림과 설명문에 "approx. TS"임을 밝힌다.
- 에너지 도표는 수치 없는 정성적 도표이며(곡선 1.6 px), 노트에서는 "보충:"으로 밝힌다.
