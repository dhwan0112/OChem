## 개요

L13은 polar 반응과 전혀 다른 방식으로 결합이 생기는 [[페리고리 반응|pericyclic reaction]]을 처음 다루고, 그 대표인 [[딜스-알더 반응|Diels–Alder 반응]]을 소개한다. 먼저 반응 메커니즘을 polar·radical·pericyclic으로 나누고, polar 방식으로 6원 고리를 만드는 다단계 경로와 DA의 한 단계 반응을 대비한다. 이어 "무엇이 반응하나 → 어떻게 반응하나 → 무엇이 빠르게 하나 → 입체화학은 어떻게 정해지나 → 왜 그런가" 순서로 정의, 협동 메커니즘과 방향족성 TS, dienophile·diene의 전자 효과와 s-cis 조건, stereospecificity와 endo 규칙을 본다. 마지막에 이 모든 것을 FMO와 Woodward–Hoffmann 규칙으로 설명한다. Regioselectivity는 L14에서 다룬다.

## 강의 흐름

### 1. 반응은 어떻게 분류되나: 극성, 라디칼, 그리고 pericyclic (슬라이드 p.3–5)
- 결합이 바뀌는 방식은 polar, radical, pericyclic 세 가지다. pericyclic 반응은 고리형 TS, 중간체 없음, concerted, stereospecific/stereoselective가 특징이다. chorismate mutase(Claisen rearrangement) 예.
- pericyclic은 cycloaddition, electrocyclic, sigmatropic으로 나뉘고, L13은 Diels–Alder만 다룬다.
- → [[페리고리 반응]]

### 2. 극성 반응으로도 6원자 고리는 만들 수 있지 않나? (슬라이드 p.6)
- Robinson annulation(Michael + aldol)과 nitro-Michael + 분자 내 SN2는 여러 단계와 이온성 중간체를 거친다. DA는 한 단계로 끝낸다.
- → [[딜스-알더 반응]], [[로빈슨 고리 형성]], [[마이클 반응]]

### 3. Diels–Alder 반응이란 무엇인가 (슬라이드 p.7–9)
- conjugated diene + alkene(dienophile) → cyclohexene. butadiene + ethylene은 165 °C, 900 atm이 필요하다. C1–C6, C4–C5 새 σ 결합과 C2=C3 새 π 결합.
- cyclic diene은 bridged bicyclic(norbornene)을 준다. Diels–Alderase 효소도 있다.
- → [[딜스-알더 반응]]

### 4. 어떻게 반응하나: 메커니즘과 전이 상태 (슬라이드 p.10–13)
- 단일 기본 단계의 concerted 반응. 열역학: π 두 개 → σ 두 개. 속도론: 6π 방향족성 TS(새 C···C 약 2.2 Å).
- 두 반응물이 suprafacial–suprafacial로 포개지는 [π4s + π2s]다.
- → [[딜스-알더 반응]], [[초면과 대면]], [[방향족성]]

### 5. 무엇이 반응을 빠르게 하나 (슬라이드 p.14–18)
- 5-1 dienophile은 EWG가 많을수록 빠르다(ethylene 900 atm → acrolein 150 °C → CH2=C(CO2Me)2 25 °C)(p.14). → [[딜스-알더 반응]]
- 5-2 diene은 EDG가 있을수록 빠르고, s-cis 형태여야 한다(butadiene 약 1%)(p.15). → [[s-cis 형태]], [[프런티어 분자 오비탈]]
- 5-3 s-cis 고정 diene(cyclopentadiene 등)은 매우 빠르고, s-trans 고정 diene은 반응하지 않는다(p.16). p.17 연습 문제는 연습 문제 1, 2. → [[s-cis 형태]]
- 5-4 cyclopentadiene은 상온에서 이량화하고, 가열·증류(retro-DA)로 단량체를 회수한다. hexachlorocyclopentadiene 부가물은 난연제(p.18). → [[역 딜스-알더 반응]]

### 6. 입체화학: 반응물의 모양이 생성물에 어떻게 새겨지나 (슬라이드 p.19–24)
- 6-1 maleate(cis) → cis, fumarate(trans) → trans: stereospecificity(p.19). → [[딜스-알더 반응]], [[입체특이성과 입체선택성]]
- 6-2 diene의 "in" 둘·"out" 둘은 1,4-cis, in + out은 trans. alkyne dienophile은 cyclohexa-1,4-diene(p.20). → [[딜스-알더 반응]], [[s-cis 형태]]
- 6-3 endo 규칙: cyclopentadiene + maleic anhydride는 endo만 준다(secondary orbital overlap). endo는 kinetic 생성물이다. p.23–24 연습은 all-cis 답(연습 문제 3). → [[endo 규칙]]

### 7. 왜 그런가: 분자 오비탈로 다시 보기 (슬라이드 p.25–31)
- 7-1 ethylene π/π*, butadiene ψ1–ψ4(HOMO ψ2, LUMO ψ3)(p.25–26). → [[프런티어 분자 오비탈]]
- 7-2 diene HOMO–dienophile LUMO 간격이 작을수록 빠르다(EDG는 HOMO↑, EWG는 LUMO↓)(p.27). → [[프런티어 분자 오비탈]]
- 7-3 양 끝 로브가 같은 면에서 만나야 해서 stereospecific하다(p.28). → [[초면과 대면]]
- 7-4 endo-dicyclopentadiene의 secondary orbital overlap(p.29). → [[endo 규칙]]
- 7-5 butadiene 두 분자는 [4+2]만 하고 [4+4]는 열적으로 안 된다(p.30). 정리 슬라이드(p.31). → [[프런티어 분자 오비탈]], [[딜스-알더 반응]]

### 8. Woodward–Hoffmann 규칙: 허용과 금지를 가르는 계산법 (슬라이드 p.32–36)
- 열적 pericyclic 반응은 (4q+2)s + (4r)a 성분 수가 홀수여야 허용된다. DA [π4s + π2s]는 합 1로 허용. "허용"은 가능하다는 뜻일 뿐이다.
- p.36 연습([4+2] 허용, [4+4] 금지)은 연습 문제 7.
- → [[우드워드-호프만 규칙]], [[초면과 대면]]

### 9. 보충: 위치선택성("ortho/para" 규칙)
- 슬라이드에는 없다. 1-치환 diene → "ortho", 2-치환 diene → "para"(L14에서 다룸).
- → [[딜스-알더 위치선택성]]
