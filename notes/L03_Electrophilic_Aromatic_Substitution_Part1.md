## 개요

L1–L2의 알켄은 Br₂나 peracid와 바로 반응했지만, C=C가 세 개 있어 보이는 benzene은 그렇지 않다. 이 강의는 "benzene은 왜 알켄과 다르게 행동하고, 어떻게 반응시키는가?"에서 출발한다. 답은 (1) Lewis acid나 진한 황산으로 훨씬 강한 electrophile을 만들어야 하고, (2) 반응하면 addition이 아니라 aromaticity를 되찾는 substitution(S<sub>E</sub>Ar)으로 끝난다는 것이다. 공통 메커니즘(cyclohexadienyl cation)을 먼저 세운 뒤 electrophile을 만드는 방법별로 halogenation, nitration, sulfonation, Friedel–Crafts alkylation·acylation을 보고, 마지막으로 OH가 고리를 activating하는 phenol을 다룬다. 고리 위 치환기의 배향 효과는 L4에서 본격적으로 다룬다. (출처: L3 p.1, p.7)

## 강의 흐름

### 0. 복습: 친전자체의 δ⁺와 알켄의 HOMO (슬라이드 p.4–5)
- 시약의 δ⁺ 부분이 electrophile이다. 아이소뷰텐 HOMO는 CH₂ 말단에 커서 Markovnikov regioselectivity를 궤도함수로 설명한다.
- → [친전자체와 친핵체](../wiki/개념/친전자체와%20친핵체.md), [마르코프니코프 규칙](../wiki/개념/마르코프니코프%20규칙.md)

### 1. 벤젠은 왜 알켄처럼 반응하지 않는가 (슬라이드 p.9–10)
- C–C 1.39 Å, 6π 전자가 고리 전체에 퍼져 있어 RCO₃H, Br₂와 반응하지 않는다. Lewis acid(AlCl₃, FeCl₃)가 있으면 Br₂와 substitution한다(1.1).
- → [방향족성](../wiki/개념/방향족성.md), [친전자성 방향족 치환](../wiki/반응/친전자성%20방향족%20치환.md), [방향족 할로젠화](../wiki/반응/방향족%20할로젠화.md), [루이스 산 촉매](../wiki/시약/루이스%20산%20촉매.md)

### 2. S<sub>E</sub>Ar의 메커니즘: 사이클로헥사다이엔일 양이온 (슬라이드 p.11)
- π 전자가 E⁺를 공격하는 단계가 rate-determining step이고, H⁺가 빠져 aromaticity가 회복된다. 양전하는 E 기준 ortho, para에만 놓인다. ipso/ortho/meta/para 용어.
- → [친전자성 방향족 치환](../wiki/반응/친전자성%20방향족%20치환.md), [arenium ion](../wiki/개념/아레늄%20이온.md)

### 3. 나이트로화 (슬라이드 p.12–13)
- 진한 HNO₃/H₂SO₄에서 직선형 NO₂⁺가 생기고, 고리가 N을 공격할 때 N=O 하나가 끊어진다. 3.1: nitro → aniline → diazonium salt → phenol.
- → [nitration](../wiki/반응/나이트로화.md), [nitronium ion](../wiki/개념/나이트로늄%20이온.md), [혼산](../wiki/시약/혼산.md), [다이아조늄 염 반응](../wiki/반응/다이아조늄%20염%20반응.md), [Pd/C](../wiki/시약/Pd-C.md)

### 4. 설폰화 (슬라이드 p.14)
- 황산 두 분자에서 HSO₃⁺가 생긴다. SO₃를 녹인 oleum도 쓴다.
- → [sulfonation](../wiki/반응/설폰화.md)

### 5. 프리델-크래프츠 알킬화 (슬라이드 p.15–17)
- 5.1 AlCl₃가 R–Cl에서 carbocation을 만든다. 5.2 1,2-hydride/methyl shift 때문에 1-클로로프로페인은 큐멘을 준다. 5.3 생성물이 더 반응성이 커서 다중 치환된다.
- → [Friedel–Crafts alkylation](../wiki/반응/프리델-크래프츠%20알킬화.md), [carbocation rearrangement](../wiki/개념/탄소%20양이온%20자리옮김.md), [탄소 양이온](../wiki/개념/탄소%20양이온.md)

### 6. 프리델-크래프츠 아실화 (슬라이드 p.18–22)
- 6.1 acylium ion이 electrophile(acid chloride 또는 anhydride). 6.2 다중 치환·rearrangement가 없다(나이트로벤젠은 용매). 6.3 acylation + Clemmensen reduction = 깔끔한 alkylation. 6.4 석신산 무수물 → α-테트랄론(빈칸 문제, 답은 L4 p.3).
- → [Friedel–Crafts acylation](../wiki/반응/프리델-크래프츠%20아실화.md), [acylium ion](../wiki/개념/아실륨%20이온.md), [Clemmensen reduction](../wiki/반응/클레멘센%20환원.md)

### 7. 페놀의 친전자성 치환 (슬라이드 p.23–26)
- 7.1 phenol은 촉매 없이 2,4,6-트라이브로모페놀이 된다("three times as rapidly"의 해석은 [방향족 할로젠화](../wiki/반응/방향족%20할로젠화.md)에 정리). 7.2 O의 비공유 전자쌍이 HOMO를 끌어올린다. 7.3 고리는 "전선", OH는 ortho/para-directing. 7.4 2,4-D, Kolbe–Schmitt(아스피린).
- → [방향족 할로젠화](../wiki/반응/방향족%20할로젠화.md), [치환기 효과](../wiki/개념/치환기%20효과.md), [Kolbe–Schmitt reaction](../wiki/반응/콜베-슈미트%20반응.md)

|---|---|---|---|
| [halogenation](../wiki/반응/방향족%20할로젠화.md) | X₂ + AlX₃/FeX₃ | X–X⁺–AlX₃⁻ | ArX |
| [nitration](../wiki/반응/나이트로화.md) | 진한 HNO₃ + 진한 H₂SO₄ | NO₂⁺ | ArNO₂ |
| [sulfonation](../wiki/반응/설폰화.md) | 진한 H₂SO₄ 또는 oleum | HSO₃⁺ | ArSO₃H |
| [F-C alkylation](../wiki/반응/프리델-크래프츠%20알킬화.md) | RX + AlCl₃ | R⁺ | ArR (rearrangement, 다중 치환) |
| [F-C acylation](../wiki/반응/프리델-크래프츠%20아실화.md) | RCOCl 또는 (RCO)₂O + AlCl₃ | RC≡O⁺ | ArCOR (한 번만) |

| 분자내 acylation | H₃PO₄ | acylium | α-테트랄론 |
| nitro 환원 | H₂, Pd/C 또는 Sn, 묽은 HCl | | ArNH₂ |
| [diazotization](../wiki/반응/다이아조늄%20염%20반응.md) → phenol | NaNO₂, HCl, 0 °C → H₂O, 가열 | aryl cation | ArOH |
| phenol bromination | Br₂, EtOH/H₂O | Br₂ | 2,4,6-트라이브로모페놀 |
| [Kolbe–Schmitt](../wiki/반응/콜베-슈미트%20반응.md) | NaOH → CO₂ → H₃O⁺ | CO₂ | 살리실산 |
